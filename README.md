# Fabric-Generator
## Fabric Roll Detection and Color Variation

This project focuses on the detection of fabric rolls in images and the generation of color variations for single fabric rolls. It leverages computer vision techniques, including Grounding DINO for object detection, Segment Anything Model (SAM) for precise segmentation, and custom logic for image classification and color extraction.

## Project Structure

The repository contains:

* (Image Processing & Object Detection):** Handles initial image classification (single vs. group), uses Grounding DINO and SAM for fabric roll detection, and generates labels in YOLO format.
* (Model Training & Color Variation):** Trains a YOLOv8 model on the generated labels and implements a robust color variation pipeline to recolor a single fabric roll based on colors extracted from other detected fabric rolls.

## Setup

To run these notebooks, you'll need a Google Colab environment with GPU access. 

### Dependencies

The notebooks automatically install the necessary Python libraries. Key dependencies include:

*   `groundingdino-py`
*   `segment-anything`
*   `supervision`
*   `ultralytics` (for YOLOv8)
*   `torchvision`
*   `scikit-learn` (for KMeans color clustering)
*   `opencv-python` (`cv2`)
*   `matplotlib`
*   `Pillow` (`PIL`)

### Google Drive Setup

Both notebooks expect specific folder structures within your Google Drive for image and label storage. Please ensure you have the following directory structure setup in your Google Drive, under a folder named `foto`:

```
MyDrive/foto/
├── assets/
│   ├── images/
│   │   ├── fresh/   # Original uploaded images
│   │   ├── train/   # Training images (split from fresh)
│   │   └── val/     # Validation images (split from fresh)
│   └── labels/
│       ├── fresh/   # Labels generated by Notebook 1
│       ├── train/   # Training labels (split from fresh)
│       └── val/     # Validation labels (split from fresh)
└── runs/            # Output directory for YOLOv8 training runs
```

## Usage

### Notebook 1: Image Processing and Object Detection

1.  **Mount Google Drive:** The notebook will prompt you to connect to your Google Drive.
2.  **Upload Images:** Place your raw fabric roll images into the `MyDrive/foto/assets/images/fresh` directory.
3.  **Run Cells:** Execute all cells sequentially. The notebook will:
    *   Classify images into 'single' or 'group' categories.
    *   Apply Grounding DINO and SAM to detect fabric rolls and generate YOLO format labels.
    *   Backup original labels before modification.
    *   Print statistics on relabeled images.
4.  **Mount Google Drive:** Ensure your Google Drive is mounted.
5.  **Run Cells (Splitting & Training):** Execute the initial cells to:
    *   Split the labeled images from `assets/images/fresh` into `train` and `val` sets.
    *   Generate a `dataset.yaml` configuration file for YOLOv8.
    *   Train a YOLOv8s model for fabric roll detection.
6.  **Evaluate and Visualize:** Review the model's performance metrics and visualize example detections.
7.  **Upload Test Images:** The notebook will prompt you to upload a single fabric image and a grouped fabric image for demonstration.
8.  **Generate Color Variations:**
    *   Detect fabric rolls in the uploaded images.
    *   Extract dominant colors from the grouped fabric rolls.
    *   Recolor the single fabric image based on the extracted colors, generating multiple variations.
    *   Save the results and display a visualization of the original and varied fabric rolls.
